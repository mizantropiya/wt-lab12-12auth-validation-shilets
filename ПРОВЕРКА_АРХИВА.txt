ПРОВЕРКА КОМПЛЕКТНОСТИ (29 октября 2026)

В пакете есть весь исходный проект WT-12, миграции EF Core, настройки локальной PostgreSQL,
файл решения .sln, Git-история и два .cmd для запуска и проверки миграций.

Уже выполнены проверки:
- содержимое ZIP после распаковки и контроль CRC;
- Git fsck и доступность ветки main;
- отсутствие повторных атрибутов DbContext/Migration в AddUsers;
- корректные кавычки SQL INSERT user student;
- наличие всех трёх миграций и исправления последовательности Id банковских счетов;
- наличие Razor Pages, Login/Profile/Session, PostgreSQL и моделей;
- доступность учебных настроек PostgreSQL в конфигурации;
- корректные пути файлов стартовых скриптов.

ВАЖНО: Сборка dotnet build и работа с Docker здесь НЕ выполнялись,
поскольку инструменты .NET SDK и Docker не установлены в среде подготовки.
Поэтому гарантировать отсутствие ошибок на произвольном Windows-ноутбуке невозможно.
Файл 01_START_WT12.cmd выполняет именно такую проверку на вашем устройстве.
